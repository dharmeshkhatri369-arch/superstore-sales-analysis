# 📊 Superstore Sales Analysis Dashboard

## 📌 Overview
This project analyzes sales, profit, and regional performance using Power BI.  
It provides actionable insights and business recommendations to support decision-making.

---

## 📈 Key KPIs
- Total Sales: 13M  
- Total Profit: 1.47M  
- Profit Margin: 11.61%  
- Total Orders: 51K  

---

## 🔍 Key Insights
- Sales show steady growth from 2011 to 2014  
- Consumer segment contributes highest revenue (51%)  
- Technology category generates the highest sales  
- Some products have high sales but low profit margins  
- Sales are below target with a gap of -1.26M  

---

## 💡 Recommendations
- Improve profit margin by optimizing pricing and reducing discounts  
- Focus on high-profit products  
- Expand in low-performing regions (Canada, Caribbean)  
- Align strategies to close the gap between actual and target sales  

---

## 🛠️ Tools Used
- Power BI  
- DAX  
- Data Modeling
